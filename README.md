## 二、项目简介
### 2.1 **项目背景**：
随着电子商务的快速发展，用户在购物时面临多个平台和不同价格的选择。本项目旨在通过一个商品比价网站，让用户能够实时查询商品在多个电商平台上的价格，方便用户进行价格对比和决策。
### 2.2 **项目目标**：
实现一个多平台商品比价网站，帮助用户在多个电商平台（如淘宝、京东）上快速获取商品的实时价格信息和历史价格趋势图表，以优化购物决策。

## 三、系统架构设计
### 3.1 **总体架构图**：
### 3.2 **前端**：
前端主要负责页面展示和用户交互，提供用户注册、登录、商品搜索和价格展示功能。这里，我们选择**React**作为本项目的前端框架。React是由Facebook开发和维护的用于构建用户界面的JavaScript库。React的基础是组件，我们可以将用户界面分解成独立的、可复用的组件，实现组件化开发，并利用其虚拟DOM优化渲染性能。
#### 3.2.1 **React项目结构**
**public/**： 存放静态文件，如index.html，所有的React组件都会在index.html中加载。
**src/**： 存放项目的主要代码，包括：
  - **App.js**：主要的应用组件，React应用的根组件。
  - **index.js**：应用的入口文件，负责将React组件渲染到index.html中。
#### 3.2.2 **React核心概念**
  - **组件**：React组件是React应用的基本组成单位，可以理解为一个可复用的UI模块。
  - **JSX**：JavaScript XML，是一种JS的语法扩展，可以在JS代码中嵌入HTML标签。
  - **虚拟DOM**：虚拟DOM是一个JS对象，是实际DOM的轻量级副本。当状态或数据发生改变时，React会生成新的DOM树，并与旧的DOM书进行比较，只更新差异部分，从而提高性能。

### 3.3 **后端**：
后端部分在整个应用中主要负责处理业务逻辑、与数据库交互、处理 API 请求并返回数据。这里，我们选择**Node.js**和**Express** 框架来开发。
#### 3.3.1 **Node.js**
  - Node.js是一个基于Chrome V8引擎的JavaScript运行环境，可以让JavaScript运行在服务器端。
  - Node.js使用事件驱动、非阻塞I/O模型，使其轻量和高效，非常适合构建高性能的网络应用。
#### 3.3.2 **Express**
  - Express是一个基于Node.js的Web应用框架，提供一系列强大的功能，如路由、中间件、视图等。
  - Express可以帮助我们快速搭建Web应用，并提供一系列的API接口，方便前端调用。
#### 3.3.3 **Node.js项目结构**
```bash
my-app-backend/
├── config/               # 配置文件
│   └── db.js             # 数据库连接配置
├── controllers/          # 控制器（处理具体的业务逻辑）
│   ├── authController.js # 用户注册、登录相关逻辑
│   ├── productController.js # 商品信息相关逻辑
├── models/               # 数据库模型
│   ├── User.js           # 用户模型
│   ├── Product.js        # 商品模型
├── routes/               # 路由
│   ├── authRoutes.js     # 用户注册、登录路由
│   ├── productRoutes.js  # 商品查询、价格记录路由
├── middleware/           # 中间件
│   └── authMiddleware.js # 身份验证中间件
├── .env                  # 环境变量
├── app.js                # 主应用文件
└── server.js             # 启动服务器
```

## 四、页面与功能设计
### 4.1 页面布局
- **首页（Home）**：包含用户登录、注册入口，商品搜索框。
- **搜索结果页面（SearchResults）**：展示不同电商平台的商品价格。
- **商品详情页面（ProductDetails）**：展示商品历史价格的图表和详细信息。
- **用户注册/登录页面（Register/Login）**：提供用户注册和登录功能。

### 4.2 主要功能模块
- **用户管理**：
  - **注册**：用户可以创建账号，填写用户名、密码、邮箱，表单包括必要的格式验证。
  - **登录**：用户通过用户名和密码登录系统，登录后可以查看价格提醒、设置个人偏好。
- **商品搜索**：
  - **搜索框**：用户输入商品名称，触发搜索，调用后端API。
  - **搜索结果展示**：展示多平台的商品价格信息（如淘宝、京东），包括商品名称、价格、平台链接。
- **价格展示**：
  - **实时价格展示**：通过API或爬虫获取电商平台的实时价格。

### 4.3 路由配置
使用React Router进行页面导航配置：
- `/` - 首页（Home）
- `/search` - 搜索结果页面（SearchResults）
- `/product/:id` - 商品详情页面（ProductDetails）
- `/login` - 用户登录页面（Login）
- `/register` - 用户注册页面（Register）

## 五、数据库设计
- **数据库选型**：MySQL
- **表结构**：
  - **用户表（users）**：
    - `user_id`（主键）：用户ID
    - `username`：用户名
    - `password_hash`：密码哈希
    - `email`：用户邮箱
  - **商品表（products）**：
    - `id`（主键）：商品ID
    - `product_name`：商品名称
    - `source_platform`：商品来源平台
    - `price`：商品价格
    - `link`：商品链接
    - `created_at`：创建时间
    - `updated_at`：更新时间

## 六、API接口设计
### 6.1 接口列表
- **用户注册接口**：`POST /api/register` - 注册新用户
- **用户登录接口**：`POST /api/login` - 用户登录
- **商品搜索接口**：`GET /api/search?query=商品名称` - 查询商品
- **实时价格接口**：`GET /api/price?product_id=ID` - 获取商品实时价格
